## Проверенные исправления

1. **Версия Python для необязательного решателя.** В README теперь прямо требуется Python ≥3.11 для закреплённых NumPy и SciPy. Такой же комментарий добавлен в `requirements-optional.txt`. Это согласуется с метаданными установленных `numpy==2.3.5` и `scipy==1.17.0`, у обоих `Requires-Python: >=3.11`. Указание Python ≥3.10 для стандартных проверок сохранено отдельно.

2. **Устаревшие результаты повторного запуска.** Перед началом каждой проверки runner удаляет её ожидаемый выходной JSON, если он существует. Поэтому провал или таймаут этой проверки до записи нового JSON не оставляет на его месте прежний PASS. Кроме того, `run_summary.json` со статусом RUNNING записывается после инициализации и до запуска проверок, затем обновляется после каждой проверки. Прерывание во время выполнения проверок не сохраняет прежний общий PASS. Итоговый PASS присваивается только после завершения всех шести проверок и только если каждая получила PASS. При прерванном запуске отдельные файлы ещё не начатых проверок могут относиться к предыдущему запуску; актуальность результатов определяется новым `run_summary.json`.

## Остальные проверенные свойства

- `independent_checks.py` получает временную папку `code` первым аргументом. Перед этим runner копирует туда `paper/majority_6040_note.tex`, необходимый для фиксации хеша статьи. Пути согласованы.
- Успешная проверка требует одновременно кода завершения 0 и одного из явно разрешённых статусов JSON. Таймаут трактуется как INCONCLUSIVE; общий неуспех возвращает ненулевой код завершения.
- Дочерние интерпретаторы запускаются без флага оптимизации; `PYTHONOPTIMIZE` удалён из окружения. Поэтому проверки через `assert` не отключаются из-за оптимизации родительского процесса.
- Код выполняется во временной копии; стандартный выход результатов — `reproduced_results/`. При стандартном вызове архивная папка `results/` не перезаписывается.
- `build_paper.py` копирует текущий самодостаточный LaTeX-файл во временную папку, выполняет два прохода `pdflatex`, проверяет ненулевой код завершения и сообщения о неразрешённых ссылках. PDF и журнал копируются по путям, указанным в README. В просмотренном существующем `paper/build.log` не было предупреждений о неразрешённых ссылках.
